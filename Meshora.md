# Meshora

**Meshora — Built for Teams and Tribes**

Meshora is a fully open-source, self-hostable communication and collaboration platform designed to unify communities, teams, and creators into one modular system.

It combines real-time chat, voice, video, streaming, collaboration tools, governance systems, and extensible plugins into a single scalable infrastructure.

---

# 🌐 Vision

Meshora is built to be a foundation layer for online communities:

- No platform lock-in  
- No algorithmic manipulation  
- No hidden moderation  
- No artificial limits on communities, channels, or users  
- Fully self-hostable and community-owned

# 🧱 Architecture Overview

### Backend
- Rust or Go core services  
- WebSocket-based real-time engine  
- REST API gateway  
- Microservice architecture  

### Frontend
- SvelteKit or Vue  
- Real-time reactive UI  
- PWA installable client  

### Storage
- PostgreSQL (primary)  
- Redis (cache/event system)  
- SQLite (lightweight deployments)
